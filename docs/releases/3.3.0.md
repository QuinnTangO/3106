## 新增

### 开屏广告缓存精准锁死

- 内置 26 个应用、65 条广告缓存路径，覆盖淘宝、京东、大众点评、中国移动、腾讯视频、番茄小说、携程等常见开屏广告目录。
- 在 `Documents` / `Library/Caches` / `Library/Application Support` / `tmp` 做浅层扫描，匹配 `KSAdSDK`、`BUAdSDK`/Pangle、`GDTMobSDK`、`BaiduMobAd`、`SplashAd`、`LaunchAd`、`TADCache` 等 SDK 目录与常见广告配置文件。
- 目录锁死：清空已落盘素材后写入 0 字节 `.erosion_adlock`（`0444`），目录设为 `0555`，防止目录被删除重建；恢复时设回 `0755` 并移除占位。
- 配置文件锁死：写入最小合法空 JSON/Plist 后设为 `0444`。
- AppGroup 共享组扫描；系统组、代理工具组、`SplashBoard`/`WebKit`/`Cookies`/`Downloads`、容器根与符号链接均排除。
- 白名单：应用 / AppGroup / 精确路径三类规则，默认 `com.smzdm.client.ios` 防崩溃种子可删除；加入白名单自动恢复已锁目标。
- 自定义路径：只允许应用容器或 AppGroup 内的子路径，添加前展示路径与风险确认。
- 一键全锁 / 全部恢复；文件浏览中可定位并高亮目标；配置文件支持只读预览。

### 缓存清理器锁目录保护

- 扫描、测量与删除均识别 `.erosion_adlock`：整棵子树跳过，不计入可清理体积，不删除占位。
- 测量缓存升级为 v2，结果弹窗显示跳过的锁目录数量。

### Gestalt 电池保护

- iPhone 15 / 15 Plus、iPhone 16 及之后机型、现代 iPad 原生显示电池循环次数与生产日期；`legacyBattery` 预设在这些机型上锁定关闭。
- 若该预设已经开启，显示关闭建议并允许用户关闭，不强制锁定开启状态。

## 升级说明

- 覆盖安装不会重弹引导页。
- 广告锁死会清空目标广告目录；恢复读写不会恢复已清空的素材。
- 本功能只阻止已落盘素材，广告网络请求仍会发生；建议搭配代理工具的网络规则使用。
